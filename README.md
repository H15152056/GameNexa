# GameNexa — Bame-inspired redesign

The GameNexa content/data and existing routes are preserved, while the visual system has been redesigned around the supplied Bame esports template reference: dark gaming UI, neon-green accents, angular/clipped cards, Rajdhani/Poppins typography, tournament-style hero presentation, and responsive layouts.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

The `src/data` content remains the source of truth for games, news, guides and character data.
